# 일일 보고서 추가 방법

앱의 **일일 보고서** 탭은 이 폴더의 파일을 그대로 읽습니다. 빌드는 없습니다. 파일 하나와 목록만 갱신하면 앱에 나타납니다.

## 경로와 형식

- `reports/YYYY-MM-DD.md` — 그날의 보고서. 날짜는 한국시간 기준입니다.
- `reports/index.json` — 날짜 목록. **맨 위가 최신**입니다.

마크다운에서 앱이 그리는 요소는 제목(`#`, `##`, `###`), 표, 목록(`-` 또는 `1.`), 링크(`[글자](https://…)` 또는 주소 그대로), `**굵게**`입니다.

## 매일 하는 일

1. `reports/2026-11-22.md`처럼 날짜 파일을 새로 만듭니다.
2. `reports/index.json`의 `reports` **맨 위**에 같은 날짜를 넣습니다.

```json
{
  "reports": [
    { "date": "2026-11-22", "title": "오늘의 망고 일일 보고서" },
    { "date": "2026-11-21", "title": "오늘의 망고 일일 보고서" }
  ]
}
```

`date`는 파일 이름과 같아야 합니다. `title`은 생략해도 됩니다. 날짜 버튼에는 마우스를 올리면 이 이름이 보이고, 화면 제목은 마크다운 첫 제목입니다. 앱은 목록 순서와 상관없이 날짜가 늦은 보고서를 먼저 엽니다.

3. 두 파일을 커밋해서 `main`에 올립니다. GitHub Pages가 기존과 같이 루트를 배포합니다.

배포 주소: https://jxlovewewe-commits.github.io/fruit-calculator/

앱은 보고서를 열 때마다 주소에 시각을 붙여 다시 받아 옵니다. `main`에 올라간 뒤 Pages에 반영되면 새로고침 없이 날짜 탭을 다시 열어도 보입니다.
